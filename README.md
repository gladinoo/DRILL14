## 📐 2. 새의 정확한 비행 애니메이션 개발 논리 (상세 설명)

본 프로젝트는 강의 슬라이드(LEC 16 - 시간)의 **물리값 정의 및 시간 동기화 기법**을 기반으로, 실제 조류(Bird)의 생물학적·물리학적 비행 역학(Flight Dynamics)을 모델링하여 구현되었습니다.

### 2.1. 2D 게임 월드의 물리적 기준 축척
- 강의 슬라이드 23의 기준 물리값을 동일하게 적용:
  $$\text{PIXEL\_PER\_METER} = \frac{10.0\text{ px}}{0.3\text{ m}} \approx 33.333\text{ px/m}$$
- 즉, **10 픽셀 = 30 cm**, **1 미터 = 약 33.33 픽셀**입니다.

### 2.2. 새의 크기 (Wingspan & Scale)
- 실제 야생 조류(예: 비둘기, 왜가리, 매 등 중대형 조류)의 날개폭(Wingspan)은 약 $0.8 \sim 1.2\text{ m}$ 수준입니다.
- 게임 캔버스($1600 \times 600$)에서 지상 캐릭터인 소년($100 \times 100\text{ px}$, 약 2.2m 신장 모델)과의 시각적 균형과 역동적인 날갯짓의 가시성을 확보하기 위해, 원본 스프라이트 시트 비율($183.6 : 168.67$)을 유지하여 **가로 $100\text{ px}$, 세로 $92\text{ px}$**로 렌더링하도록 설정하였습니다.

### 2.3. 비행 속도 (Flight Speed) 모델링
- 실제 조류의 순항 비행 속력은 일반적으로 **$30.0 \sim 50.0\text{ km/h}$** (약 $8.33 \sim 13.89\text{ m/s}$)입니다.
- 군집을 이루는 10마리의 새마다 현실적인 개체 차이를 부여하기 위해 **$30.0 \sim 48.0\text{ km/h}$ 범위의 무작위 속도**를 배정합니다:
  $$\text{speed\_mps} = \frac{\text{speed\_kmph} \times 1000}{3600}$$
  $$\text{speed\_pps} = \text{speed\_mps} \times \text{PIXEL\_PER\_METER}$$
- 시간 기반 수평 이동:
  $$x_{\text{next}} = x_{\text{current}} + (\text{dir} \times \text{speed\_pps} \times \Delta t)$$

### 2.4. 날갯짓 주기 (Wingbeat Cycle) 및 애니메이션 프레임 속도 (Action FPS) 연동
강의 슬라이드 28의 **소년 보폭 공식**을 조류의 생체 역학에 맞추어 1:1로 대응 모델링하였습니다.
- **소년의 보폭(Stride) $\leftrightarrow$ 조류의 1회 날갯짓(Wingbeat Stroke)**
- `bird_animation.png`의 1회 날갯짓 전체 사이클은 **총 14개의 스프라이트 프레임**(`TOTAL_FRAMES = 14`)으로 구성되어 있습니다.
- 실제 조류가 1회 날갯짓을 할 때 전진하는 평균 수평 거리(Advance per stroke)를 약 $3.0\text{ m}$로 정의합니다:
  $$\text{flaps\_per\_second} = \frac{\text{speed\_mps}}{\text{distance\_per\_flap\_m}} = \frac{\text{speed\_mps}}{3.0}$$
- 따라서 1초당 재생해야 할 애니메이션 프레임 수($\text{FPS}$)는 다음과 같이 계산됩니다:
  $$\text{frames\_per\_second} = \text{flaps\_per\_second} \times \text{TOTAL\_FRAMES} = \left(\frac{\text{speed\_mps}}{3.0}\right) \times 14$$
- 이를 통해 **더 빠르게 날아가는 새일수록 공기역학적으로 날갯짓을 더욱 빠르게 퍼덕이는 지극히 사실적인 애니메이션**이 완성됩니다.
- 시간 기반 프레임 갱신:
  $$\text{frame} = (\text{frame} + \text{frames\_per\_second} \times \Delta t) \bmod 14$$

### 2.5. 14프레임 2D 스프라이트 시트 정밀 인덱싱
- `bird_animation.png` 규격: $918 \times 506\text{ px}$ (5열 $\times$ 3행 = 총 15개 슬롯).
- 검증 결과 마지막 15번째 슬롯(Row 2, Col 4)은 Alpha=0인 빈 공간이며, 실제 프레임은 **0번부터 13번까지 총 14개**입니다.
- Pico2D는 화면 좌하단($y=0$) 기준이므로 상단 행부터 역순으로 Y 오프셋을 계산:
  - **Row 0 (Frame 0 ~ 4):** `bottom = 338`, `height = 168`
  - **Row 1 (Frame 5 ~ 9):** `bottom = 169`, `height = 169`
  - **Row 2 (Frame 10 ~ 13):** `bottom = 0`, `height = 169`
  - **Col 0 ~ 4:** 각 열의 정확한 픽셀 너비($183 \sim 184\text{ px}$)와 시작 좌푯값을 사전 계산된 룩업 테이블(`FRAME_COORDS`)로 관리하여 단 1픽셀의 오차나 번짐도 발생하지 않도록 최적화하였습니다.

### 2.6. 좌우 비행 방향 전환 및 수평 반전 (Flip)
- 스프라이트 원본 새는 오른쪽을 응시하고 있습니다.
- **오른쪽 비행 (`dir = 1`):** `clip_composite_draw(..., 0.0, '', ...)` (원본 렌더링)
- **왼쪽 비행 (`dir = -1`):** `clip_composite_draw(..., 0.0, 'h', ...)` (수평 반전 렌더링)
- **화면 경계 반사 (Boundary Bounce):**
  - 새의 몸체 중심 기준 좌우 반폭(`half_w = 50px`)을 고려하여,
  - $x \ge 1600 - 50$ 도달 시 `dir = -1` 전환
  - $x \le 50$ 도달 시 `dir = 1` 전환

### 2.7. 10마리 새떼 군집(Flock) 다양성 연출
10마리의 새가 완전히 같은 궤적과 타이밍으로 움직이는 부자연스러움을 배제하기 위해 개별 인스턴스마다 다음과 같은 독립 변수를 부여하였습니다:
1. **초기 수평 위치 $x$:** $100 \sim 1500\text{ px}$ 균등 랜덤 배치
2. **비행 고도 $y$:** $260 \sim 540\text{ px}$ 고도 분산 (지상 잔디 위 하늘 공간)
3. **비행 방향:** 오른쪽($+1$) 또는 왼쪽($-1$) 무작위 결정
4. **비행 속력:** $30.0 \sim 48.0\text{ km/h}$ 사이 개체별 속도 차이
5. **날갯짓 위상 (Initial Frame Phase):** $0.0 \sim 13.9$ 범위의 난수를 초깃값으로 주어, 새마다 날개 치는 박자가 제각각 엇갈리도록 구현

## 🎮 3. 실행 및 조작 방법

```bash
# 실행 명령 (main.py 또는 run.bat)
python main.py
```

| 키 입력 | 기능 설명 |
| :---: | :--- |
| **`ESC`** | 프로그램 종료 |
| **`D`** | **디버그 모드 토글** (각 새의 실시간 비행 속도 km/h, 프레임 레이트 fps, 비행 방향 HUD 표시) |
| **`R`** | **새떼 재배치** (10마리 새의 위치, 고도, 속도를 새롭게 무작위 초기화) |
| **`◀` / `▶`** | 지상 소년 좌우 달리기 이동 |
| **`SPACE`** | 지상 소년 공 발사 |
